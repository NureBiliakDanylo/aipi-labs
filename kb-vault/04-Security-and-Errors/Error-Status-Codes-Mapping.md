# Error Status Codes Mapping

Матриця відповідності виняткових бізнес-ситуацій Nom-Nom-Save стандартним кодам помилок HTTP.

## Ключові положення
| Код стану | Семантика | Використання в Nom-Nom-Save |
|---|---|---|
| `400 Bad Request` | Синтаксична помилка, невалідний JSON або порушення формату | Помилка валідації полів при реєстрації, некоректний формат дати |
| `401 Unauthorized` | Відсутня або невалідна автентифікація | Відсутній чи прострочений Access Token у запиті |
| `403 Forbidden` | Недостатньо прав на виконання операції | Клієнт намагається змінити налаштування чужого ресторану |
| `404 Not Found` | Запитаний ресурс відсутній | Бокс або замовлення з вказаним ID не існує |
| `409 Conflict` | Конфлікт із поточним станом сутності | Спроба купити розпроданий бокс, некоректний перехід у FSM |
| `422 Unprocessable Content` | Семантична помилка валідації | Сума замовлення менша за мінімальний поріг транзакції |
| `429 Too Many Requests` | Перевищено ліміт запитів (Rate Limit) | Забагато запитів від однієї IP-адреси чи клієнта за хвилину |
| `500 Internal Server Error` | Непередбачена критична помилка сервера | Падіння з'єднання з БД, необроблений виняток у коді |
| `503 Service Unavailable` | Сервіс тимчасово недоступний | Планові регламентні роботи або перевантаження черги |

## Приклад
Якщо передати `quantity: -3` при бронюванні, API повертає `400 Bad Request` із переліком помилок схеми. Якщо передати `quantity: 2`, але на залишку лише 1, API повертає `409 Conflict`.
