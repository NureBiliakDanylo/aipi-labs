# RFC 9110 HTTP Semantics

RFC 9110 є актуальним базовим стандартом протоколу HTTP, який кодифікує семантику методів, заголовків та кодів відповідей.

## Ключові положення
- **Класифікація методів**: стандарт суворо розмежовує безпечні методи (Safe: GET, HEAD, OPTIONS), що не змінюють стан сервера, та ідемпотентні методи (Idempotent: GET, HEAD, PUT, DELETE), повторний виклик яких дає той самий стан.
- **Статус-коди**: коди відповідей поділено на 5 класів (1xx Інформаційні, 2xx Успіх, 3xx Перенаправлення, 4xx Клієнтські помилки, 5xx Серверні помилки).
- **Обробка мутацій**: для створення сутностей визначено POST (з поверненням 201 Created та заголовка Location) або PUT (якщо клієнт контролює URI).

## Приклад
При створенні замовлення в платформі Nom-Nom-Save клієнт відправляє POST запит на `/api/v1/orders`. Відповідно до стандарту, сервер повертає статус `201 Created` із заголовком `Location: /api/v1/orders/ord_102`.
