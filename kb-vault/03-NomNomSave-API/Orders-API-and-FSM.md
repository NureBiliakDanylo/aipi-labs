# Orders API and FSM

Підсистема Orders API забезпечує оформлення, оплату, генерацію цифрового чека та верифікацію видачі замовлення за QR-кодом.

## Ключові положення
- **Створення замовлення (`POST /api/v1/orders`)**:
  - Клієнт передає `boxId`, `quantity`, `paymentMethod`.
  - Транзакційно зменшується `quantity` боксу в БД.
  - Створюється запис замовлення у стані `CREATED`.
  - Повертається `201 Created` з одноразовим кодом отримання (`pickupCode`).
- **Стейт-машина статусів**:
  1. `CREATED`: очікує підтвердження або онлайн-оплати.
  2. `CONFIRMED`: підтверджено рестораном, готується до пакування.
  3. `READY_FOR_PICKUP`: бокс спаковано, очікує на клієнта у визначене вікно.
  4. `COMPLETED`: ресторан відсканував QR-код клієнта, замовлення видано.
  5. `CANCELLED`: скасовано до настання вікна видачі.
- **Скасування замовлення (`POST /api/v1/orders/{id}/cancel`)**:
  - Дозволено лише до переходу в `READY_FOR_PICKUP`. При спробі скасувати пізніше повертається `409 Conflict`.

## Приклад
При успішному скануванні QR-коду робиться виклик:
`POST /api/v1/orders/ord_991/verify-pickup`
Тіло: `{"pickupCode": "NNS-8472"}`. При успіху повертається `200 OK` зі статусом `COMPLETED`.
