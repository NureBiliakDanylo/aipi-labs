# kb-agent: AI-агент з базою знань Obsidian та Chroma

Проєкт розроблено в межах Лабораторної роботи № 2 з дисципліни «Штучний інтелект».
Студент: Біляк Данило Тарасович, група ПЗПІ-23-5.

## Структура репозиторію
- `kb/`: модулі взаємодії зі сховищем Obsidian, розбиття на фрагменти, ембединги, векторне сховище Chroma, інкрементний індексатор та інструменти дій.
- `agent/`: цикл ReAct-агента, компонент рішень, валідатор простору дій, стан та обробка помилок.
- `baseline.py`: реалізація базових ліній експерименту (one-shot та наївний RAG).
- `eval/`: контрольний набір запитів `retrieval_set.json` та верифікатор обґрунтованості цитувань `citations.py`.
- `tests/`: 10 модульних тестів на pytest, що працюють повністю автономно без зовнішніх API.
- `traces/`: зафіксовані файли трасувань кроків агента.

## Запуск
```bash
# 1. Індексація сховища
python -m kb.indexer

# 2. Пошук по базі знань
python -m kb.search "Як оформити відповідь при конфлікті версій?"

# 3. Запуск агента
python main.py "Який HTTP статус повернути, якщо клієнт намагається скасувати виконане замовлення?"

# 4. Запуск тестів
pytest -v
```
