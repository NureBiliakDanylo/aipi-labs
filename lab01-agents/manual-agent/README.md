# manual-agent

Мінімальний освітній AI-агент із детермінованим середовищем кодів стану HTTP (RFC 9110 / REST API серверної частини «Nom-Nom-Save») та власним циклом прийняття рішень Observe-Reason-Act-Evaluate без використання сторонніх агентних фреймворків.

## Предметна область
Коди стану протоколу HTTP (RFC 9110, Section 15; MDN Web Docs; специфікація REST API «Nom-Nom-Save»).
Середовище містить перевірені факти про коди `200`, `201`, `204`, `301`, `304`, `400`, `401`, `403`, `404`, `409`, `500`, `503`.

## Встановлення та запуск

1. Налаштувати змінні оточення у файлі `.env`:
   ```bash
   cp .env.example .env
   # Вказати власний GEMINI_API_KEY з Google AI Studio
   ```

2. Запуск тестів:
   ```bash
   uv run pytest
   ```

3. Запуск агента:
   ```bash
   uv run python main.py "Коли повертати 400, 401 чи 403?"
   ```

4. Запуск базової лінії (one-shot без циклу агента):
   ```bash
   uv run python main.py "Коли повертати 400, 401 чи 403?" --mode oneshot
   ```
